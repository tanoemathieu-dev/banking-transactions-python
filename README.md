# Nettoyage & Analyse de Transactions Bancaires

## Description
Nettoyage et analyse exploratoire d'un dataset de 200 transactions bancaires.

## Outils
- Python (Pandas, Matplotlib)

## Ce que fait le script
- Nettoyage : gestion des valeurs manquantes, détection d'anomalies sur les montants
- Correction d'incohérences (statuts, catégories, types de transactions)
- Analyse : Top 10 clients, catégories les plus actives, dates les plus productives
- Visualisation avec Matplotlib
- Export structuré en Excel multi-feuilles (8 onglets)

## Fichiers
| Fichier | Description |
|---|---|
| `nettoyage_analyse.py` | Script principal |
| `donnees_bancaires_sales.xlsx` | Données brutes (avant nettoyage) |
| `donnees_bancaires.xlsx` | Données nettoyées et analysées |
